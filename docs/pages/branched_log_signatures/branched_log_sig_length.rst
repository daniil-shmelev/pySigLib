pysiglib.branched_log_sig_length
================================

.. autofunction:: pysiglib.branched_log_sig_length

For ``planar=True``, this is the scalar-free length used by MKW methods 1, 2,
and 3. It counts weighted Lyndon forests through the requested total node degree.
For ``planar=False``, it is the scalar-free BCK log-signature length and counts
decorated nonplanar rooted trees.
