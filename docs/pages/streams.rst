Streams
========================

.. meta::
   :description: Incrementally compute signatures and log signatures over streaming or sliding-window paths with pySigLib.

Stateful classes for incremental signature and log-signature computation over
streaming or sliding-window paths. These support efficient push/pop operations
and O(1) arbitrary interval queries via Chen's identity.
